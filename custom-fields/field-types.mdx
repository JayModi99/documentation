# Field types

| Type | Notes |
|------|-------|
| Text, TextArea, Numeric, Currency | Scalar |
| DatePicker, DateTime | Temporal |
| Checkbox | Boolean |
| DropDown, RadioButton, MultiSelect | **Options required** |
| Url, Email, Phone | Validated formats |
| User | User picker |
| File | Uploaded file reference |

Required ⇒ ShowInForm must be true.
