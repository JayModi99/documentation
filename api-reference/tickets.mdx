# Tickets API

| Method | Path | Permission |
|--------|------|------------|
| GET | `/` | `tickets.view_all` |
| GET | `/my` | `tickets.view` |
| GET | `/assigned` | view |
| GET | `/export` | export |
| GET | `/my/export` | export |
| GET | `/assigned/export` | export |
| GET | `/{id}` | view |
| GET | `/{id}/activity` | view |
| POST | `/attachment-upload-urls` | view |
| POST | `/` | create |
| PUT | `/{id}` | update |

| PUT | `/{id}/reopen` | resolve |
| DELETE | `/{id}` | delete |
| POST | `/{id}/comments` | comment |
