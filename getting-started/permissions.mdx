# Permissions & RBAC

Permissions are string keys stored as a JSON array on `Role.Permissions`. Controllers enforce them with `[RequirePermission]` / `[RequireAnyPermission]`.

## Permission catalog (shipped)

| Module | Keys |
|--------|------|
| Companies | `companies.view/create/edit/delete/manage_settings` |
| Sites | `sites.view/create/edit/delete/import/export/manage_categories` |
| Locations | `locations.view/create/edit/delete/import/export/manage_types` |
| Departments | `departments.view/create/edit/delete/import/export/manage_categories` |
| Categories | `categories.view/create/edit/delete/import/export` |
| Brands | `brands.view/create/edit/delete/import/export` |
| Models | `models.view/create/edit/delete/import/export/manage_brands/manage_categories` |

| Asset kits | `assetkits.view/create/edit` |
| Checkout / Check-in | `checkout.view/create`, `checkin.view/create` |
