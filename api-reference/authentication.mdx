# API authentication

## User APIs

```http
Authorization: Bearer <access_token>
Content-Type: application/json
```

Obtain tokens via `POST /api/v1/auth/login` or SSO callback. Refresh with `POST /api/v1/auth/refresh-token`.

## Agent APIs

Enrollment:

```http
X-Org-Token: <plaintext_org_token>
Content-Type: application/json
```

Steady-state:

```http
Authorization: Bearer <device_jwt>
```

Device JWTs are rejected outside `/api/v1/agent/*` by `DeviceJwtScopeMiddleware`.
