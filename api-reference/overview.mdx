# API overview

| Item | Value |
|------|-------|
| Base path | `/api/v1` |
| Versioning | Hardcoded in routes (no ASP.NET versioning package) |
| JSON | camelCase; ignore nulls; string enums |
| Auth | Bearer JWT (user) or device JWT on `/api/v1/agent/*` |
| Envelope | `ApiResponse<T>` / paged wrappers |
| Health | `GET /health` |
| SignalR | `/api/v1/agent/commands-hub` |

Swagger title in Development: **AssetMate Pro API V1**.
