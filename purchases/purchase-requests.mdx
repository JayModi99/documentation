# Purchase requests

## Status machine

```
Draft ──submit──► PendingApproval ──approve──► Approved ──convert──► Converted
  ▲                    │
  │                    ├─reject──► Rejected
  │                    └─send back──► Draft
  └──── edit Approved forces Draft ────┘
```

`Cancelled` enum exists — **no cancel API**.

## Line rules

≥1 line; qty &gt; 0; est. cost ≥ 0; Asset/Consumable line needs model or description.

## Endpoints

| Method | Path | Permission |
