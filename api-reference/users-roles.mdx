# Users & roles API

## Users — `/api/v1/User`

| Method | Path | Permission |
|--------|------|------------|
| GET | `/` | `users.view` |
| GET | `/export` | `users.export` |
| GET | `/import/template` | `users.import` |
| POST | `/import` | `users.import` |
| GET | `/{id}` | `users.view` |
| POST | `/invite` | `users.create` |
| PUT | `/{id}` | `users.edit` |
| PATCH | `/{id}/status` | `users.edit` |
| DELETE | `/{id}` | `users.delete` |
| POST | `/{id}/resend-invite` | `users.edit` |
| POST | `/{id}/reset-password` | `users.edit` |
| GET | `/{id}/activity` | `users.view` |
| GET | `/assignable` | `tickets.assign` |

## Roles — `/api/v1/Role`

| GET | `/permissions` | `roles.view` |
