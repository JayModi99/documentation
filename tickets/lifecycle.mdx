# Ticket lifecycle

```
Create ──► Open
Assign ──► InProgress
Hold ◄──► Open/InProgress
Resolve ──► Resolved
Close ──► Closed
Cancel ──► Cancelled
Reopen ──► Open (from Resolved or Closed only)
```

Terminal for most edits: Closed, Cancelled. Delete blocked if already assigned. New tickets must use an Open-stage status.
