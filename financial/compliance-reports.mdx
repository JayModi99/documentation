# Compliance reports

| Endpoint | Notes |
|----------|-------|
| `GET /api/v1/Depreciation/it-block-summary?fy=` | Income Tax block summary |
| `GET /api/v1/Depreciation/compliance-report?fy=` | Compliance report payload |
| `GET /api/v1/Depreciation/compliance-report/export` | File export (`type` query optional) |

Permission: `depreciation.view`.
