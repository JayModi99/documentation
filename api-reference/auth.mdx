# Auth API

Base: `/api/v1/auth`

| Method | Path | Auth | Body |
|--------|------|------|------|
| POST | `/register` | Anonymous | `RegisterRequest` |
| POST | `/verify-email` | Anonymous | `VerifyEmailRequest` |
| POST | `/resend-otp` | Anonymous | `ResendOtpRequest` |
| POST | `/login` | Anonymous | `LoginRequest` |
| POST | `/refresh-token` | Anonymous | `RefreshTokenRequest` |
| GET | `/my-companies` | Authorize | — |
| POST | `/switch-company` | Authorize | `SwitchCompanyRequest` |
| POST | `/setup-company` | Authorize | `CreateCompanyRequest` |
| POST | `/logout` | Authorize | `RefreshTokenRequest` |
| POST | `/forgot-password` | Anonymous | `ForgotPasswordRequest` |
| POST | `/reset-password` | Anonymous | `ResetPasswordRequest` |
| POST | `/verify-reset-otp` | Anonymous | `VerifyEmailRequest` |
| POST | `/change-password` | Authorize | `ChangePasswordRequest` |
| POST | `/setup-password` | Authorize | `SetupPasswordRequest` |

```bash
curl -X POST "$API/api/v1/auth/login" \
  -H "Content-Type: application/json" \
  -d '{"email":"admin@acme.com","password":"SecurePass1!"}'
```
