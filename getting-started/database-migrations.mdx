# Database migrations

Migrations live under:

- `backend/src/AssetMatePro.Infrastructure.Postgres/Migrations/`
- SQL Server provider project (when used)

## Patterns

| Pattern | Implementation |
|---------|----------------|
| Soft delete | `BaseEntity.IsDeleted` + global query filter |
| UTC timestamps | Converter on all `DateTime` columns |
| Audit | `AuditableEntity.CreatedBy` / `UpdatedBy` set in `SaveChangesAsync` |
| Concurrency | `RowVersion` on `Device`, `DeviceCommand` |

## Applying migrations

Use the project's standard EF tooling (see `docs/dotnet-commands.md`). Production deployments apply pending migrations on startup when configured.
